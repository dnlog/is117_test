# Signal, Story, and Style

*A short guide to persuasion, brand meaning, visual design, and directing AI-assisted work.*

This mini textbook is for first-year students learning how products, messages, and interfaces guide attention and make meaning. Each chapter builds on the last: first understand persuasion, then explore brand archetypes and design language, apply them to one ordinary white T-shirt, and finally use the framework to direct AI work responsibly.

Read the chapters in order on a first pass. Then return to the case study when you need a concrete example, and use the final chapter as a checklist for planning an AI-assisted project.
